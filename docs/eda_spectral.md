# Просмотр спектральных FITS

`stringlensing/eda_spectral.py` читает первый числовой HDU каждого файла и строит обзорный спектр. При наличии линейной спектральной WCS в `CRVAL1`, `CDELT1`/`CD1_1`, `CRPIX1` ось строится по этим карточкам; иначе используется индекс пикселя. Многомерный массив сводится к первому срезу по всем несpectralным осям. Скрипт **не** делает потоковую/длиноволновую калибровку и не участвует в фотометрическом анализе космической струны.

Из корня проекта:

```bash
stringlensing/venv/bin/python stringlensing/eda_spectral.py \
  targets_spectra/HCT_14102025_A2213/tfdcrb25.ms.fits \
  --output result_spectral_preview.png
```

PNG и короткая сводка о HDU выводятся локально. `result*` исключён из Git. Если FITS не содержит числового массива, скрипт завершится понятной ошибкой. Для научного анализа спектра сначала нужны калибровки прибора и явный выбор области/апертуры.
